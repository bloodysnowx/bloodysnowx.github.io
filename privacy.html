プライバシーポリシー

最終更新日：2026年11月10日

「kurochan-gws」は、開発者（bloodysnowx）が自分の Google アカウントのデータを、自分の PC 上のコマンドラインツールから扱うための個人用アプリケーションです。一般の方への提供は行っていません。

1. 取得する情報

Google の OAuth 認証で利用者が許可した範囲で、Google Drive のファイルおよびファイル情報（ファイル名、フォルダ構成など）にアクセスします。

2. 利用目的

取得した情報は、利用者本人の指示に基づくファイルの検索・閲覧・作成・整理のためだけに使用します。作業の補助として、利用者本人が使用する AI アシスタント（Claude Code）が、利用者の指示に応じて内容を処理する場合があります。

3. 保存と管理

認証情報（アクセストークン等）は利用者の PC 上にのみ保存され、開発者が運営するサーバーへ送信されることはありません。

4. 第三者への提供

取得した情報を販売したり、広告に利用したり、第三者に提供したりすることはありません。

5. Google API サービスのユーザーデータに関するポリシーへの準拠

本アプリケーションによる Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

6. アクセス権の取り消し

本アプリケーションへのアクセス許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

7. お問い合わせ

GitHub（bloodysnowx）までご連絡ください。

Privacy Policy

Last updated: November 10, 2026

"kurochan-gws" is a personal application that lets its developer (bloodysnowx) access their own Google account data from a command-line tool on their own computer. It is not offered to the public.

  • Data accessed: Google Drive files and file metadata, within the scopes the user grants via Google OAuth.
  • Use: Only to search, read, create, and organize files at the user's own request. An AI assistant used by the user (Claude Code) may process the content as directed by the user.
  • Storage: Credentials are stored only on the user's computer and are never sent to any server operated by the developer.
  • Sharing: Data is never sold, used for advertising, or shared with third parties.
  • Compliance: Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access: Access can be revoked at any time from your Google Account's third-party apps page.
  • Contact: GitHub (bloodysnowx)
